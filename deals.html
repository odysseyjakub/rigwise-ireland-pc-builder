WHAT A LISTING NEEDS

Evidence before exposure.

01

Exact product

Model and part number match a known component, with a working product page.

02

Real seller and price

Seller identity, VAT treatment, currency and a dated observed price are recorded.

03

Ireland checkout

Delivery eligibility and charges are supported by evidence for the Republic of Ireland.

04

Honest freshness

Stock and last-confirmed time are visible; stale or uncertain offers are not called live.

Public data needs permission and context.

Manufacturer pages help identify hardware, but they are not retailer offers. Public retailer pages, affiliate feeds and marketplace APIs can have different reuse rules and may omit final Irish checkout costs. We’re researching permitted sources; none is enabled in this demo.

BEST NEXT ROUTE

Retailer or Awin product feeds

Feeds can carry model IDs, price, currency, stock and product links. Currys IE, Paradigit.ie and BuyItDirect.ie are candidates, but their feeds require account access and comparison-use permission. Actual Ireland delivery and checkout costs still need validation.

Awin publisher feed guideAwin API authentication
BEST AGGREGATOR LEAD

Kelkoo publisher Shopping API

Kelkoo documents offer search and feeds, and lists Ireland among its markets. Offer fields can include last-update time, price, delivery cost, stock, GTIN/MPN and tracked product links. Requests need a secret Publisher Center JWT. We have no account or Irish PC merchant sample, and order-level shipping still needs validation.

Open Icecat

Could broaden product specifications, not current shop prices. Registration and an open-content licence apply, including attribution and redistribution terms; this project has not imported or accepted that licence.

GATED PROGRAMME API

Amazon.ie Creators API

An official API exists, but marketplace eligibility and qualifying-sales requirements apply. Associates policies also set conditions for price display and comparison. No Amazon access is configured, and fit with a mixed-retailer comparison needs review.

WRITTEN APPROVAL NEEDED

eBay.ie Browse API

The Ireland marketplace is supported, but API access alone does not grant price-comparison rights. eBay’s licence restricts pricing-tool use and requires prior written consent for the relevant restricted use.

Supported marketplaceseBay API licence
NOT A RETAILER SEARCH API

Google Merchant API

Google's API manages products in a merchant's own Merchant Center account. It requires an account and product data source; it does not provide a public search of other shops' live offers.

Google Products API scope
PAID PROVIDER

PriceAPI

A commercial service advertises aggregated retailer and marketplace price data; its current public plans start at €99/month after a trial. Irish PC coverage, comparison-use terms, final delivery costs and stock accuracy still need a sample and written review.

Current PriceAPI pricing

Best next step: inspect an eligible Kelkoo Irish merchant sample alongside authorised direct/Awin feeds. These are authenticated or permission-based routes, not open anonymous datasets. A paid provider may broaden coverage only after a sample confirms Irish stock and checkout data and the contract permits comparison. We found no anonymous, reusable Irish live-price feed among the sources checked; that is not proof none exists. We will not replace missing permission with scraping.
