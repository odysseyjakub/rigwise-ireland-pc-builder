## Current boundary

The current app uses only synthetic fixtures. A retailer's existence, product catalogue, or published programme does not make its offers live or eligible. A feed marked "available" is a lead to check access and licence terms, not blanket permission for every use. Do not add a retailer to comparison results until the required feed access and offer-level delivery and tax evidence have been validated.

## Feed import groundwork

awin-feed.js accepts a licensed Awin CSV/TSV export as text and normalises its source fields, including item price, currency, stock, identifiers, deep links, delivery fields, and timestamps. The site's collapsed feed-review panel runs that parser locally in the visitor's browser; the file is not uploaded or saved. It counts exact GTIN/brand-MPN matches, ambiguous rows, unmatched rows and parser rejects against the sample fixtures and manufacturer-sourced reference catalogue. It does not request feeds, verify publisher credentials, or change the offers used by the builder. Imported records remain ineligible for the app's cheapest-price results unless separate evidence confirms publisher permission, a unique exact product match, fresh stock and price data, an exact listing link, Irish delivery, the retailer's order-level shipping rule, and tax treatment. The feed's per-product delivery field is retained as source evidence; it is not assumed to be the final consolidated order charge.

## Public-data options checked

- **Awin retailer feeds are not anonymous public feeds.** Awin says publisher feeds can be downloaded through its interface or feed-list endpoints, but its publisher guide describes the list as the feeds the signed-in publisher can access. Awin API calls require a personal OAuth 2.0 bearer token and account permissions. Some advertisers enable “soft membership” for auto-join programmes, but Awin describes that as applying only to selected advertisers; it is not blanket access. Public programme profiles that say “product feed available” do not prove this project's publisher can retrieve or reuse that feed. Sources: [Awin Product Feed Publisher Guide](https://help.awin.com/developers/docs/product-feed-publisher-guide-intro), [Awin API authentication](https://help.awin.com/apidocs/api-authentication), and [Awin Publisher FAQs](https://help.awin.com/developers/docs/faqs-for-publishers).
- **Open Icecat is a possible product-content source, not a retailer-offer source.** Icecat advertises free content from 600+ brands, but access requires registration. Its Open Content License includes attribution, warranty-disclaimer, redistribution and share-alike obligations for content and derived works. This project has not accepted that licence or imported its data; a commercial comparison service needs a reviewed distribution plan first. Sources: [Open Icecat content subscription](https://icecat.com/content-subscription/) and [Open Content License v1.4](https://iceclog.com/open-content-license/).
- **Amazon.ie has an official product API, but it is gated and has comparison-specific rules.** Amazon's Creators API locale list includes Ireland. Current onboarding requires an accepted Associates account for the target marketplace, at least 10 qualifying sales in the previous 30 days, API registration and credentials. Amazon.ie policies permit showing prices only when served with the link or retrieved via its API under the licence; cross-retailer price comparison must also show Amazon's lowest new price and, when supplied, lowest used price. The policy restricts using Amazon Program Content to promote non-Amazon products and generally disallows price tracking/alerts without agreement. This project has no Associates account or API credentials, and the mixed-retailer display rules need explicit review before integration. Sources: [Creators API Ireland locale](https://affiliate-program.amazon.com/creatorsapi/docs/en-us/locale-reference), [Creators API eligibility](https://affiliate-program.amazon.com/creatorsapi/docs/), and [Amazon.ie Associates Program policies](https://affiliate-program.amazon.ie/help/operating/policies).
- **eBay.ie exposes Browse API search, but it is not an unrestricted public comparison feed.** The official marketplace matrix supports `EBAY_IE`; Browse calls require an application access token. The API licence restricts using eBay content in ways that compete with eBay or derive/model eBay listing prices, and its restricted-API pricing-tool section requires eBay's express prior written consent. Since Rigwise compares and optimises purchase prices across sellers, do not ingest or display eBay offers until eBay confirms in writing that this use is permitted. Sources: [Browse API search](https://developer.ebay.com/develop/api/buy/browse_api/item/search), [marketplace support matrix](https://developer.ebay.com/api-docs/buy/static/ref-marketplace-supported.html), and [eBay API License Agreement](https://developer.ebay.com/support/api-license-agreement).
- **Manufacturer specification pages are usable as individually checked references.** The new [components catalogue](components.html) records model identifiers and selected facts from manufacturer product pages or datasheets, links each record to its source, and avoids copying product imagery. It does not prove current retailer stock or qualify any purchase offer.
- **OpenStreetMap can supply mapped shop candidates, not retail offers.** The Irish mapping community documents traditional county boundaries at `admin_level=6` and uses names such as `County Laois`; the site searches Dublin City plus the three surrounding local-authority areas. It offers a user-triggered county lookup for named `shop=computer` and `shop=electronics` records through the Europe Overpass service. OSM data is under the ODbL and results link back to OSM with attribution. This is a low-volume, cached prototype lookup: the public endpoint has no availability guarantee and may block abusive use. Mapped records can be incomplete or stale and do not show whether a business is open, sells PC components, or has stock or collection available. Do not use OSM as a retailer feed or present mapped points as verified retail recommendations. Sources: [OpenStreetMap Ireland boundary guide](https://wiki.openstreetmap.org/wiki/Ireland/Boundaries), [OpenStreetMap Ireland county query guide](https://www.openstreetmap.ie/resources-2/tools/using-overpass-turbo-to-extract-data-from-openstreetmap/), [OpenStreetMap licence and attribution](https://www.openstreetmap.org/copyright), [Europe Overpass service and fair-use terms](https://ovp.dresel.systems/en/).

**Recommended offer-data route:** start with direct, approved retailer/Awin product-feed access for Currys IE, Paradigit.ie and BuyItDirect.ie, then validate each feed's comparison-use terms and Irish delivery fields. If no retailer feed is granted, ask the retailer for a CSV/JSON export and permission in writing. Icecat may broaden sourced product specifications after licence review, but will not supply offers. Amazon requires an established qualifying Associates account and has constraints that may not fit this mixed-retailer optimiser; eBay needs written permission for pricing-tool use. No API credentials or feed access are available in the current project.

The official source checks performed for the listed candidates did not reveal an unauthenticated, reusable Irish retail feed for current component prices. This is not an exhaustive claim that no such service exists. Do not scrape retailer pages as a substitute for permission. The next data milestone needs approved retailer/Awin feed access or a separately licensed offer provider, with comparison-use rights and Irish checkout evidence confirmed.
